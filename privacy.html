foodsync privacy policy

Last updated 16 November 2026.

foodsync is a personal tool with one user, its owner. It runs on the owner's own computer. This page describes how it handles data from the owner's Google account.

What foodsync reads from Google

Body measurements in Google Health, which in practice means the owner's weigh-ins (date and weight). foodsync also reads back the nutrition entries that it added itself, to confirm that each meal arrived once and only once.

What foodsync writes to Google

Nutrition entries in Google Health: for each meal a name, a time, calories, protein, carbohydrate, fat and some micronutrients. foodsync can change or delete only the entries that it added.

Where the data is kept

  • The permission that Google gives foodsync (an access token) is stored in a file on the owner's computer. It is not sent anywhere except back to Google.
  • A delivery journal on the same computer records which meals have been delivered.
  • Recent weigh-ins and the day's totals are written to a status file in the owner's own Google Drive, where the owner's own personal tools read them to show progress.

There is no foodsync server and no foodsync database on the internet.

Sharing

None. Data from Google is not sold, not shared with any other person or company, not used for advertising, and not used to develop or train artificial-intelligence or machine-learning models. It is used only to show the owner their own food log and weigh-ins.

Google API Services User Data Policy

foodsync's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Switching it off and deleting data

  • Access can be withdrawn at any time in the Google Account, under Third-party apps and services. foodsync then stops working until access is given again.
  • Entries that foodsync added can be deleted in Google Health like any other entry.
  • Deleting foodsync's folder on the owner's computer removes the stored permission and the delivery journal.
